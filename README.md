# 🌊 Acerca de Topsify

**Topsify** simula una plataforma global de streaming musical que maneja grandes cantidades de datos relacionados con:

- 🎵 Canciones
- 👤 Usuarios
- 📊 Estadísticas
- 📂 Playlists
- 🎧 Streams
- 🌎 Información global

El proyecto está orientado al aprendizaje y práctica de:

- SQL
- SQLite
- Consultas avanzadas
- Análisis de datos
- Testing automatizado
